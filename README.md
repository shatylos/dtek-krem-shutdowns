# dtek-krem-shutdowns

Go-модуль для отримання інформації про відключення світла за адресою з сайту
[ДТЕК Київські регіональні електромережі](https://www.dtek-krem.com.ua/ua/shutdowns):

- поточне відключення за адресою: причина, час початку й орієнтовний час відновлення;
- черги (групи) графіка, до яких належить будинок;
- погодинний графік черги на сьогодні й завтра та готові інтервали відключень.

## Вимоги

Сайт захищений Imperva Incapsula, яка не пропускає звичайні HTTP-клієнти. Тому модуль
відкриває сторінку в headless Google Chrome (або Chromium) через
[chromedp](https://github.com/chromedp/chromedp). Chrome має бути встановлений на машині,
де працює програма.

## Встановлення

```sh
go get github.com/shatylos/dtek-krem-shutdowns
```

## Використання

```go
client := dtekkrem.NewClient()
defer client.Close()

res, err := client.Lookup(ctx, dtekkrem.Address{
	City:   "м. Бориспіль",
	Street: "вул. Київський Шлях",
	House:  "6",
})
if err != nil {
	return err
}

if res.Outage != nil {
	fmt.Printf("Світла немає до %s: %s\n", res.Outage.End.Format("15:04"), res.Outage.Reason)
}
for _, group := range res.Groups {
	fmt.Println(group.Name) // "Черга 2.2"
	for _, in := range group.Outages() {
		fmt.Printf("  %s – %s (можливо: %t)\n", in.Start.Format("02.01 15:04"), in.End.Format("02.01 15:04"), in.Maybe)
	}
}
```

Місто, вулицю та будинок треба писати так само, як на сайті: `м. Бориспіль`, `с. Горенка`,
`вул. Київський Шлях`. Повний список міст і вулиць повертає `client.Streets(ctx)`. Регістр і
пробіли в номері будинку не важливі. Для адрес без номерів будинків `House` залишають порожнім.

Якщо адресу не знайдено, `Lookup` повертає `ErrUnknownCity`, `ErrUnknownStreet` або `ErrUnknownHouse`.

Будинок, який живиться від кількох ліній, належить до кількох черг. Квартири в ньому можуть
відключатися за різними графіками, тому `Result.Groups` містить усі черги будинку.

## Обмеження

- Кожен запит відкриває сторінку в новій вкладці, це займає приблизно 4–5 секунд. Браузер
  запускається під час першого запиту й працює до `Close`.
- Якщо звертатися до сайту часто (десятки завантажень за пів години), Incapsula на якийсь час
  блокує запити, і `Lookup` повертає `ErrBlocked`. Опитуйте сайт не частіше ніж раз на кілька
  хвилин.
- Модуль повторює запити, які робить форма на сайті. Якщо ДТЕК змінить сайт, модуль може
  перестати працювати.
